# TOPBoard — рисовалка для интерактивной доски

Программа для рисования поверх экрана. Создана для интерактивных досок.

## Управление
- Кнопка **Рисовать** — включить/выключить режим рисования
- **Карандаш** — рисовать
- **Ластик** — стирать
- **Очистить** — очистить всё
- **Сохранить** — сохранить рисунок в .bmp
- **Цвет** — переключить цвет (красный/синий/зелёный)
- **Размер** — переключить толщину (1/3/5/10)
- **Закрыть** — выйти

## Сборка
1. Установи MinGW
2. Запусти `build.bat`
